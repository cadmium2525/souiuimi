# CASE 04「1万円弱」— 作者向けの語義と出題設計

2026-10-15。v8で、ユーザーが指定した「1万円弱は、1万円未満か、1万円を少し超えるか」を題材に追加しました。今回の改修では依頼番号と担当者番号の表引きを撤去し、依頼した本人との会話に集中する構成へ改めました。この文書は制作者向けの設計記録です。

## 語義の確認

金額などの数量につく「弱」は、示した基準より少し少ないことを表します。「1万円弱」は1万円を少し下回る額です。少し超える意味で使うなら「強」に当たります。小学館の辞書の該当用法を確認し、説明文は本作向けに要約しました。

- [コトバンク「弱」](https://kotobank.jp/word/%E5%BC%B1-524777)：小学館『精選版 日本国語大辞典』などの再掲。
- [goo辞書「弱」](https://dictionary.goo.ne.jp/word/%E5%BC%B1/)：小学館『デジタル大辞泉』の再掲。

上記を2026-10-15に確認しています。辞書本文の長文転載はせず、ゲーム内の校正メモと結果解説は自作の要約です。「少し超える」も「弱」の正しい語義だと教える構成にはしません。

## 語義と、この人の意図

本作では、依頼した本人がどの程度の額を考えていたかを、過去の発言と実額から予測します。Aの回は基準より少ない額を意図しており、辞書どおりの使い方です。Bの回は話者が「弱」と「強」を取り違えており、少し超える額を意図しています。語義そのものは両方の回で同じです。

依頼した相手は「部長」で固定します。部長と以前やりとりした「○円弱」と実際の額を2件示し、担当者を探す別表や他人の履歴は置きません。例えば部長の「5,000円弱」が5,200円、「20,000円弱」が20,300円という記録なら、少し超えるつもりで使う傾向が読み取れます。過去の例が2件あれば現実の発話も確実に決まる、という一般的な主張ではありません。

全結果解説は辞書上の意味を先に示し、次に今回頼んだ本人の言い方を説明します。Bを選んで意図と一致した場合は、上司自身が少し超えるつもりで「弱」と言っていたと認め、正しくは「強」だったと話します。この回にAを選んで不足しても、上司が自分の表現を取り違えていたと認め、プレイヤーの日本語の解釈は合っていると明言します。

## 具体的な円数の扱い

近似を表す「弱」は「必ず9,800円」のような特定の額を定義しません。本作で選べるのは、あらかじめ用意された次の2通です。

| 行動 | 金額の側 | 生成する候補 |
| --- | --- | --- |
| A | 1万円未満 | 9,300〜9,900円から100円刻み |
| B | 1万円を少し超える | 10,100〜10,700円から100円刻み |

本人の過去の言い方から下側・上側のどちらを意図しているかを予測し、その側の封筒を届けます。辞書や過去の発言だけから現在の必要額を1円単位で導き出せるとは主張しません。

選んだ封筒の額と受取額は同じ `CaseInstance` から描画・台詞へ渡します。一致すれば受け取りが完了し、少なければ不足額を示し、多ければ差額を返します。現実の立替金の依頼では具体的な金額を確認するのが自然なため、その考えも結果の主人公の台詞に残します。

## 再出題と、判断前の表示

一回に扱う依頼は一件です。話者は部長のまま、用途、過去2件の発言と実額、現在の上下の候補額を変えます。同じ部長でも出題ごとに過去のやりとりが変わり、現在の金額だけで意味が固定されないようにします。英数字の依頼・担当者コード、その対応表、前日の別担当、無関係な他の依頼は置きません。

7つの調査記録では、依頼の内容、本人とのやりとり、過去の金額、用意された封筒や受取場所、言葉についてのメモなどを確認できます。書面や会話の内容をそのまま表示し、主人公の感想や「この人は超えるつもりだ」といった先回りの解釈は加えません。調査場所の先行マーカーや未発見の記録名も表示しません。

`solveAmountFacts` は `requiredYen` の答え欄を読まず、本人の過去2件の金額が基準からどちら側にあるかでA/Bを判断します。記録不足や、使い方の方向が矛盾する記録を拒否します。`validateAmountCase` は選択肢、辞書要約、記録本文、台詞、必要額、3D表示用の値の一致を検証します。検証の実行結果は [acceptance.md](acceptance.md) に記録します。
