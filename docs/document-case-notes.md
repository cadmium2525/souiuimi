# CASE 05「資料、まとめといて」

2026-10-15、v9。ユーザーが選んだ「資料まとめといて」を、要約・配布・回収の3通りに解釈するケースです。

## 判断の対象

- A：内容の要点を1枚に要約して提出する。
- B：ページ順をそろえ、参加者分の配布セットを作る。
- C：原本を全量集めて搬出する。

当日の資料番号Pから、行先Dと受付番号Rを特定し、その組に対応する原稿内容・受渡条件を確認します。3用途の記録は毎回そろい、現在の対象、日付、番号、対応関係、記録の順番、ページ数、部数を変えます。同じ資料番号でも前日は行先が異なるため、旧メモには日付と対象を記します。

調査カードとノートは文書の原文や物の状態だけを表示します。主人公の感想や解釈、遠くから見える場所マーカー、未発見の記録名は追加しません。主な照合経路は結果の振り返りで示します。

## 演出

Aは原稿を確認して1枚を仕上げ、Bは配布セットをそろえます。Cは大部分を積み終えた状態から最後の数束を足し、巨大クリップで留めて台車で短距離運びます。固定カメラで見せ、短時間に全量を往復搬出する早送りは使いません。

Cで判断するのは「現物を全量集めて運ぶ」という仕事です。主人公より高い紙のタワーと巨大なクリップは漫画的な誇張で、受付条件が裸の巨大束や特定の梱包形状を必須にする設定ではありません。正解時は上司が当然のように受け取り、取り違えた回は用途と成果物のずれを指摘します。

7つの手がかり、探索120秒、A10秒・B12秒・C14秒。3通りすべてが当日の意図になり、全9組合せに結果があります。再挑戦は同じ出題を保持し、次の依頼は全5ケースを含む新規出題です。
