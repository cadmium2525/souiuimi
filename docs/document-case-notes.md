# CASE 05「資料、まとめといて」

2026-10-16。現在は、会議の前後・全文の配布・検討記録の所在を組み合わせて、「まとめる」の意味を判断します。以前の「3分の説明」「原本を保管室へ」という、1枚から答えがわかる記録を改めました。

## 判断する行動

- A：内容の要点を1枚に整理する。
- B：ページ順をそろえ、人数分の配布セットを作る。
- C：原本を全量集めて渡す。

上司の指示は「この研修資料、まとめといて。午後渡せるようにね」のように、資料の自然な名前で伝えます。現在時刻は13:40です。部長の共通の受取メモには、会の前は説明に使い、会の後は検討の経緯を確認するという目的があります。そのメモだけでは、どの行動かは決まりません。

## 八つの状況と、組み合わせる記録

`DocumentCaseFacts` は次の3項目を独立して持ち、全8通りが出題されます。

| 事実 | 記録 | 変化 |
| --- | --- | --- |
| 会の前後 `meeting` | 02：検討会の予定 | 15:00からの会／午前中に終了した会 |
| 全文の配布 `distribution` | 03：資料の送付記録 | 全員へ送付済み／未送付 |
| 検討記録の所在 `record` | 06：担当者の確認メモ | 原本の各ページだけ／別紙の議事メモ |

会の前は、02と03を合わせます。参加者に全文が届いていなければB、届いていれば部長が説明する要点を作るAです。記録が原本にあるか別紙にあるかは、そのときの配布作業の代わりにはなりません。

会の後は、02と06を合わせます。指摘や確認印が原本の各ページにだけあるなら、要約では元の記録をたどれないためCです。別紙に検討の記録があれば、その要点を整理して渡すAです。

| 会の状態 | 全文 | 記録 | 行動 |
| --- | --- | --- | --- |
| これから | 配布済み | 原本のみ | A |
| これから | 未配布 | 原本のみ | B |
| これから | 配布済み | 別紙 | A |
| これから | 未配布 | 別紙 | B |
| 終了後 | 配布済み | 原本のみ | C |
| 終了後 | 未配布 | 原本のみ | C |
| 終了後 | 配布済み | 別紙 | A |
| 終了後 | 未配布 | 別紙 | A |

この表は作者向けで、ゲーム内の対応表として表示しません。実際には予定と配布記録、資料の状態を読みます。「原本に書き込みがある」1枚だけなら、会の前のA/Bと会の後のCが残ります。「全文は配布済み」だけでもA/Cが残ります。会の時刻だけでも、前はA/B、後はA/Cが残ります。

`solveDocumentFacts` は予定と関係する記録を合わせて解き、演出用の `intendedChoice` を読みません。名前・ページ数・人数や全8状況の行番号は答えの根拠にしません。

## 調査と表示

7か所は、上司のチャット、検討会の予定、資料の送付記録、机に置かれた資料、部長の受取メモ、担当者の確認メモ、共用備品です。記録には観察できる内容だけを示し、主人公の感想は加えません。

資料名・日付・人数・ページ数は意図と独立に変わります。標識と物体の構成は全状況で共通で、原本を保管室へ移すと直接告げるカードはありません。調査場所を先に知らせるマーカーや、未発見の記録名も表示しません。

結果解説は2文・66字以内で、判断に使う2つの事実と今回の意味を短く示します。記録全文は折りたたみから読めます。再挑戦は同じ出題を保持し、次の依頼は新規生成します。

## 演出と検証

Aは原稿を確認して1枚を仕上げ、Bは人数分のセットをそろえます。Cは積み終わりに近い状態から最後の数束を足し、巨大クリップで留めて台車で運びます。固定カメラで見せ、短時間に全量を往復する早送りは使いません。

Cで判断するのは、元の検討記録をまとめて渡す仕事です。主人公より高い紙の束と巨大クリップは漫画的な誇張で、相手が特定の梱包形状を要求した設定ではありません。調査120秒、A10秒・B12秒・C14秒で、3意図×3行動の全9組合せに結果があります。

専用テストは、全8状況について各カードの実際の全文・題名を比較し、同じ1枚が複数の正解に現れること、必要な2枚で一意に決まることを検証します。3,000seed、本文と結末の一致、改変の拒否、出題の凍結、診断用の固定台本も確認します。ブラウザの検証結果と未確認事項は [acceptance.md](acceptance.md) に記録します。
