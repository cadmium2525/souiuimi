# 受け入れ基準・テスト指示

## P0: 合格必須
- [ ] `npm install && npm run build` が成功、`dist/index.html` と相対アセットが生成される。
- [ ] GitHub Pagesの `https://<user>.github.io/<repo>/` 相当のサブパスで読み込める（相対パス確認）。
- [ ] 360x800 / 390x844 / 320x568の縦画面で、開始・移動・調査・選択・再挑戦が可能。
- [ ] タッチジョイスティックと右側スワイプが同時に使え、スクロールやピンチでページが動かない。
- [ ] 主人公は壁・机をすり抜けず、調査対象の近くでのみ『調べる』が出る。
- [ ] 7個の手がかりがすべて調査でき、調査カードの日本語が読める。
- [ ] 調査画面、メニュー、非表示タブで残り時間が減らない。
- [ ] 5分経過または『判断する』で3択が表示される。3択すべてに固有の結果。
- [ ] Cを選ぶと『建物を箱に収納』することが映像・テキストで明確にわかる。
- [ ] リトライ時に時間・位置・発見数・選択結果が初期化される。
- [ ] PCでもWASD/マウス/Eでプレイ可能。
- [ ] 無音でもクリア可能。音の自動再生に依存しない。

## P1: できれば対応
- [ ] WebGL非対応時に丁寧な代替表示。
- [ ] 画面回転/タブ復帰で表示とタイマーが壊れない。
- [ ] 30fps前後を目標に描画負荷を抑え、重い端末でDPRを下げられる。
- [ ] `prefers-reduced-motion` で過度なカメラ演出を軽減。
- [ ] 主要操作にラベルと十分なタップ領域（44px目安）。

## 手動テストシナリオ
1. 手がかり0件で即決A→END_A→リトライ。
2. C01とC02だけ調査してB→END_B→リトライ。
3. 7件調査してC→END_C→タイトル。
4. 途中でブラウザをバックグラウンドへ→復帰後、タイマーが飛ばないこと。
5. ジョイスティックを動かしたまま調査ボタン→操作が暴走しないこと。
6. 画面回転・リサイズ・ページ再読込→破綻しないこと。

## 進捗報告の形式
各項目を `完了 / 未完了 / 未確認` として報告。未確認を完了扱いしない。実機未確認の場合は使用したエミュレーション環境を記載。
