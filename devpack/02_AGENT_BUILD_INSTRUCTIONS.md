# AIコーディングエージェント向け実装指示書

## ミッション
`01_PROJECT_BRIEF.md` と `03_STAGE_SCRIPT_AND_DATA.md` を実装の正本とし、スマホ縦画面優先のThree.js製3D探索ゲームを**GitHub Pagesにデプロイできる完成した静的Webアプリ**として作る。質問せず、明記されていない細部はMVPを壊さない簡単な実装を選ぶ。`04_ACCEPTANCE_TESTS.md`を満たすこと。

## 技術スタック
- Vite + TypeScript + Three.js。UIはHTML/CSSのオーバーレイ。Reactは不要。
- npmのロックファイルをコミット。`npm run dev`, `npm run build`, `npm run preview` が動作。
- `vite.config.ts` は `base: './'`（相対パス）を設定し、GitHub Pagesのサブパスに対応。
- 単一ページ。ルーティング不要。GitHub ActionsでGitHub Pagesに`dist/`を公開（公式のPages artifact/upload/deploy actionsを使用）。Actionsのバージョンは実装時点でサポートされる安定版を採用。
- 外部API呼び出し・サーバー・認証・収集SDKは一切なし。localStorageは音量設定・既読ヒント程度に限定（利用不可でも動作）。

## 操作仕様（最重要）
- スマホ**縦画面を正規レイアウト**とする。CSSは `100dvh` とsafe-area insetを考慮。基準360x800 CSS px、320x568でも主要UIが操作可能。
- 左下: 固定仮想ジョイスティック（pointer events、マルチタッチ、指が離れたら即停止）。左親指で移動。
- 右側の空き領域: ドラッグでカメラの水平回転。上下は角度を制限。誤操作を避けUI上のスワイプはカメラに伝播させない。
- 近くに調査物があれば右下に大きな『調べる』ボタン。タップでタイマーを一時停止し、調査UIを開く。閉じると再開。
- PC: WASD/矢印移動、マウスドラッグ視点、E調査、Escで閉じる。
- カメラは三人称・斜め後方。壁へのめり込み防止、軽い追従補間。主人公の顔が見えなくてもよいが、移動方向が視覚的にわかる。
- 画面上部: 残り時間、手がかり数、メニューボタン。調査中はゲーム内時間を停止。
- 音は初期OFF。音がなくても完全に理解できる。色だけで情報を区別しない。
- 画面回転時はUIとレンダラーを再計算。横画面でも最低限操作でき、縦持ち推奨を表示。

## 3D実装
- 最初はプリミティブ（BoxGeometry等）と簡単なマテリアルだけでオフィス・机・椅子・PC・張り紙・コンテナ・窓・主人公を作る。テクスチャは必須ではない。
- 床をXYではなくXZ平面、Y上方向とする。部屋の目安12m x 9m、短い廊下3m x 5m。移動可能範囲を明示し、簡易AABB衝突で家具をすり抜けない。
- 手がかりオブジェクトは近接判定とハイライトで発見しやすくする。遠くからタップで誤選択しない。
- 3D内の細かな日本語は描画しなくてよい。『調べる』でHTMLカードに大きな文字と詳細を表示する。
- 描画負荷: `devicePixelRatio`上限1.5（低性能端末は1.0）、シャドウは原則OFF、光源少数、ポストプロセスなし。アニメーションはrequestAnimationFrame。非表示タブでは時間経過を止める。
- WebGL利用不可時は操作不能画面にせず、エラーと推奨環境を表示。

## 状態遷移
`TITLE -> INTRO -> EXPLORE -> INSPECT -> EXPLORE -> DECISION -> ENDING -> TITLE/RETRY`。
- 5分経過でDECISIONに移行。プレイヤーが任意に『判断する』を押して早期決断も可能。
- `INSPECT` / メニュー / タブ非表示ではタイマー停止。
- 選択肢は3つとも常時選択可能。手がかり未収集でもCを選べる。推理ゲームであり、証拠収集はロック解除ではない。
- 結果に『見つけた証拠』『見逃した証拠』を簡潔に表示。失敗したらやり直し可能。
- すべての状態で二重タップ・多重イベントによる重複進行を防ぐ。

## データ駆動
手がかり、セリフ、エンディングをTSの配列/オブジェクトで管理。ゲームロジックに日本語文字列をハードコードしない。データは `03_STAGE_SCRIPT_AND_DATA.md`に従う。

## 実装順序
1. Vite/TS/Three.js起動・Pagesビルド。
2. 縦画面UIとジョイスティック・三人称カメラ・衝突。
3. オフィスと調査対象、近接調査、カードUI。
4. タイマーと状態遷移、3択、3エンディング。
5. C選択時の『カメラが引いて建物ごと箱に入る』演出。難しければ3Dで建物縮小＋箱移動＋テキストの演出で代替。
6. リトライ、サウンド設定、レスポンシブ調整、実機検証、Pages公開。

## エージェントへの成果物要求
動作するソース一式、README（起動/ビルド/Pages設定）、スクリーンショット、既知の制約、手動テスト結果。テストできなかった項目は未確認と記す。ライセンス表記が必要な外部依存を明示。
